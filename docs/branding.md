Brand Essence
Tagline: Every Moment, Perfectly Framed
Brand Promise: Technical excellence meets creative vision to create visual legacies that endure.
Brand Personality: Professional, Sophisticated, Reliable, Detail-Oriented, Premium

Color Palette
Primary Colors

Primary background color
Main text color on light backgrounds
Conveys sophistication and premium quality
Usage: 60% of design elements

Accent color for highlights and emphasis
Secondary graphics and icons
Metallic finish for premium materials
Usage: 25% of design elements

Clean space and breathing room
Secondary background for contrast
Usage: 15% of design elements

Typography
Primary Typeface: Montserrat
Bold (700): Headlines, Logos
SemiBold (600): Subheadings
Regular (400): Body text
Rationale: Modern, clean, professional with excellent readability
Secondary Typeface: Inter
For UI elements, captions, and technical specifications
Ensures clarity in smaller sizes
Type Scale
H1 (Hero): 48-64px, Montserrat Bold
H2 (Section Headers): 36-42px, Montserrat SemiBold
H3 (Subsections): 24-28px, Montserrat SemiBold
Body Text: 16-18px, Inter Regular
Caption/Small: 12-14px, Inter Regular
Type Treatment Rules
Minimum body text size: 16px
Line height: 1.5-1.6 for body text
Letter spacing: Slightly increased (+0.5px) for all-caps headings
Never use pure white text on pure black (use #E5E5E5 on #0A0A0A for better readability)
